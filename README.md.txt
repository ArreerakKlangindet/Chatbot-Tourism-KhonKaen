# การออกแบบและการพัฒนาแชทบอทเพื่อการท่องเที่ยวในจังหวัดขอนแก่น 
### (Chatbot Design and Development for Tourism in Khon Kaen)

โปรเจกต์นี้เป็นแชทบอทระบบแนะนำข้อมูลการท่องเที่ยวในจังหวัดขอนแก่นครับ พัฒนาขึ้นมาเพื่อช่วยให้นักท่องเที่ยวหรือผู้ที่สนใจ สามารถค้นหาสถานที่ท่องเที่ยว ร้านอาหาร คาเฟ่ ที่พัก รวมถึงข้อมูลการเดินทางในขอนแก่นได้ง่ายๆ ผ่าน LINE แอปพลิเคชัน โดยระบบจะตอบกลับข้อมูลเป็นแบบ Interactive ทำให้ใช้งานง่ายและตอบโจทย์ผู้ใช้จริง

## 🛠️ เครื่องมือและเทคโนโลยีที่ใช้ (Tech Stack & Tools)

โปรเจกต์นี้ออกแบบโครงสร้างโดยแบ่งแยกส่วนการทำงานชัดเจน เพื่อให้ระบบมีความเสถียรและสามารถพัฒนาต่อยอดได้ง่ายครับ

### 1. Front-end / User Interface
* **LINE Messaging API:** เลือกใช้เป็นแชนแนลหลักในการสื่อสารกับผู้ใช้ เพราะเข้าถึงคนไทยได้ง่ายที่สุด ไม่ต้องบังคับให้ผู้ใช้โหลดแอปใหม่เพิ่ม
* **LINE Flex Messages:** ออกแบบหน้าตาการตอบกลับให้สวยงาม น่าใช้งาน (ทำเป็นพวกการ์ด Carousel แนะนำสถานที่ท่องเที่ยว มีรูปภาพ รายละเอียด และปุ่มให้กดเปิดพิกัดแผนที่ได้ทันที)

### 2. Back-end & Server Logic
* **Node.js (JavaScript):** ใช้เป็น Runtime หลักของ Server หลังบ้านในการจัดการ Logic การโต้ตอบของบอท
* **Express.js:** ใช้ทำ Webhook Endpoint คอยรับ-ส่งข้อมูล Event Payload ต่างๆ กับทาง LINE API
* **Python (`app.py`):** มีการนำมาใช้ร่วมด้วยในส่วนของการจัดการคัดกรอง หรือประมวลผลข้อมูลสคริปต์เสริม เพื่อให้ระบบมีความยืดหยุ่น

### 3. DevOps & Version Control
* **Docker & Docker Compose:** ใช้จัดการทำ Containerization คลุม Environment ทั้งหมดของระบบ ช่วยให้เวลาส่งต่อโปรเจกต์หรือรันเซ็ตอัปเพื่อเทสระบบ (Local Setup) ทำได้เร็ว ไม่เจอปัญหาเรื่อง Environment ตีกัน
* **Git & GitHub:** ใช้จัดการควบคุมเวอร์ชันของโค้ด (Version Control) และเก็บประวัติการพัฒนาอย่างเป็นระบบ

## 🚀 ฟีเจอร์เด่นๆ ของแชทบอท (Key Features)
* **Interactive Tourism Guide:** ค้นหาและแนะนำสถานที่ท่องเที่ยว โดยแบ่งหมวดหมู่ชัดเจน (ธรรมชาติ, วัดและวัฒนธรรม, คาเฟ่/ร้านอาหาร)
* **Rich Component Responses:** ดึงความสามารถของ LINE Flex Messages มาใช้เต็มที่ มีรูปสวยๆ พร้อมปุ่มกดลิงก์เปิด Google Maps นำทางได้เลย
* **Clean & Structured Code:** โครงสร้างโปรเจกต์แยกโมดูลชัดเจน (แบ่งฝั่ง Routes, Data และการจัด Template FlexMessages) ทำให้โค้ดอ่านง่ายและ Maintain ง่าย
